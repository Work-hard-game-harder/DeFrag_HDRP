# #2 탈출구 열림 — 롱테이크 스토리보드 (초안 v1, 2026-10-02)

- 재생 시점: 발전기 B 가동 → 서버 다운로드 100% 직후. `B1FEscapeSequence`의 Exit 슬롯(`exitVideo`).
- 두 플레이어가 그 순간 어디에 있는지 알 수 없으므로, 특정 방이 아닌 "전력이 막 돌아온 B1F 흰 복도"로 연출한다.
- 소품: 요원 A는 해킹패드, 요원 B는 무전기(가슴)와 카메라. 장갑 없음, 맨손.
- 모델: 클링 3.0 Standard 720p, 오디오 끔(초당 80). 소리는 VO·효과음을 따로 만들어 편집에서 입힌다.

## 테이크 A — 무전 (10~12초, AI 영상)
- 장소/조명: B1F 흰 연구소 복도. 방금 전력이 돌아와 천장 조명이 하나씩 차갑게 켜지고, 가장자리에는 비상등의 붉은 기운이 남아 있다.
- 시작 프레임: 요원 B의 어깨 너머. 요원 A가 든 해킹패드 화면에 청록색 "DOWNLOAD 100%".
- 흐름: 카메라가 천천히 밀고 들어간다 → B의 가슴 무전기 LED가 깜빡이고 B가 손을 올려 누른다 → 두 사람이 멈춰 귀를 기울인다 → 카메라가 반원을 그리며 돌아 두 사람 정면 투샷 → A가 해킹패드를 가슴 높이로 든다.
- VO (조력자, 진중한 남성, 무전 필터, 영어):
  - "Download's complete. Good work, both of you." (다운로드 완료됐다. 잘했다, 둘 다.)
  - "I've found an emergency exit down to B2. Sending it to your map now." (지하 2층으로 내려가는 비상구를 찾았다. 지금 맵으로 전송하지.)

## 인서트 — B1F 지도 (약 5초, 게임 실시간, 0크레딧)
- 해킹패드 위로 반투명 2D 홀로그램 지도가 펼쳐진다. 실제 B1F 도면(`FacilityBlueprint`, NavMesh 기반)을 그대로 쓴다.
- 지도가 스캔 라인과 함께 그려지고, 현재 위치 점 → 비상구 위치에 빨간 마커가 깜빡이며 "EMERGENCY EXIT // B2" 표시.
- 이유: AI 영상은 지도를 지어내므로 실제 맵과 다르다. 게임 도면을 써야 플레이어가 실제로 길을 찾을 수 있다.

## 테이크 B — 출발 (6~8초, AI 영상)
- 장소/조명: 테이크 A와 같은 복도. 앞에 떠 있는 지도에서 나오는 빨강·청록 빛이 두 사람의 바이저에 비친다.
- 시작 프레임: 두 요원 정면 미디엄샷, 가운데 아래쪽에 지도 빛(지도 자체는 화면 밖 또는 흐림).
- 흐름: 두 사람이 서로 마주보고 짧게 고개를 끄덕인다 → 카메라가 뒤로 빠지며 위로 올라가 복도 끝까지 담는 와이드 → 두 사람이 비상구 방향으로 몸을 돌린다 → 검게 페이드아웃.
- VO (조력자, 사용자 승인): "Move. Before it finds you again." (움직여. 놈이 다시 찾아내기 전에.)
