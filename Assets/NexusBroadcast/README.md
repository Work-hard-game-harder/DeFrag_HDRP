# NEXUS TV Broadcast

`Nexus_Public_Service_Broadcast.mp4` is a silent 1280×720, 24 fps H.264 loop-ready in-world TV asset.

Sequence: bait information → noise → normal public campaign → noise → bait information → signal loss → noise.

Run `Build-NexusBroadcast.ps1` from PowerShell to regenerate the video. It requires `ffmpeg` on `PATH` and uses Windows Malgun Gothic fonts for Korean typography.
